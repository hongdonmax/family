# ⭐ 우리 아이 칭찬 스티커판

다윤(유니)이와 세린(리니)이를 위한 칭찬 스티커판 프로그램이에요.
잘한 일에 **칭찬 도장**을 주고, 도장을 많이 모으면 **동물 스티커**를 받는 방식입니다.

- 유니의 칭찬스티커판 (아들 · 최다윤)
- 리니의 칭찬스티커판 (딸 · 최세린)

설치할 것이 전혀 없고, 인터넷이 없어도 됩니다. 데이터는 그 기기에 자동으로 저장돼요.

---

## 📱 시작하는 방법 (절차)

1. `index.html` 파일을 **더블클릭**하면 인터넷 브라우저(크롬, 사파리 등)에서 열립니다.
2. 화면 위쪽에서 **유니(다윤)** 또는 **리니(리니)** 버튼을 눌러 아이를 선택해요.
   - 유니는 파란색, 리니는 분홍색 테마로 바뀌어요.
3. 끝! 바로 도장을 줄 수 있어요.

> 휴대폰/태블릿에서 쓰려면 즐겨찾기(북마크)나 홈 화면에 추가해 두면 편해요.

---

## 👏 칭찬 도장 주는 방법

1. 아이가 잘한 일을 골라 해당 버튼을 **한 번 누르면** 도장이 하나 쌓여요.
   - 📚 숙제 잘하기
   - 🛁 잘 씻기
   - 🍚 밥 잘 먹기
   - ⏰ 잘 일어나기
   - 👵 할머니·할아버지 말씀 잘 듣기
   - 🏡 하지집 할머니 말씀 잘 듣기
   - 👪 엄마·아빠 말씀 잘 듣기
   - 🦷 양치 잘하기
2. 도장을 누르면 "참 잘했어요!" 축하 화면이 잠깐 떠요.
3. **실수로 눌렀다면** 빼기:
   - 컴퓨터: 버튼을 **마우스 오른쪽 클릭**
   - 휴대폰/태블릿: 버튼을 **꾹 길게 누르기**

---

## 📅 달력으로 매일매일 기록하기

- 달력은 **한국 기준**(일요일 시작, 일~토 요일 표시)이에요. 오늘 날짜는 색 테두리로 표시돼요.
- 날짜 칸에는 ⭐ 아래에 **그날 받은 도장 수**가 보여요.
- **날짜를 누르면** 그 날이 선택되고, 아래 "칭찬 도장 주기"가 그 날짜에 적용돼요.
  - 그래서 **지난 날짜도 눌러서 도장을 더하거나 뺄 수 있어요.** (깜빡한 날 나중에 채우기/고치기 가능)
- 위쪽 `‹` `›` 로 달을 넘기고, **"오늘로 이동"** 버튼으로 오늘 날짜로 바로 돌아와요.
- 달력 아래에 "이번 달 도장 ○개" 요약이 보여요.

---

## 🎁 동물 스티커 받는 방법

- 도장을 **10개** 모으면 동물 스티커를 **한 개** 받아요. (강아지 🐶 → 고양이 🐱 → 토끼 🐰 ...)
- 받은 동물 스티커는 "받은 동물 스티커" 칸에 차곡차곡 모여요.
- 동물 스티커를 받아도 모은 도장은 그대로 누적돼서 다음 스티커를 향해 계속 모을 수 있어요.

> **도장 개수를 바꾸고 싶다면?**
> 맨 아래 "⚙️ 부모님 설정"에서 동물 스티커 1개에 필요한 도장 수를 1~50개로 바꾼 뒤 **저장**을 누르세요.
> (예: 더 어린 아이는 5개로 낮춰 자주 칭찬받게 할 수 있어요.)

---

## ⚙️ 부모님 설정

- **동물 스티커 1개에 필요한 도장 수**: 기본 10개. 아이 수준에 맞게 조절하세요.
- **도장 잘못 줬을 때**: 그 항목 버튼을 **오른쪽 클릭(또는 길게 누르기)** 하면 한 개씩 빠져요.
  (아이가 실수로 모두 지우는 일이 없도록 전체 초기화 버튼은 두지 않았어요.)

---

## 💾 저장 안내

- 기본 상태에서는 모든 기록이 **그 기기의 브라우저 안에** 자동 저장됩니다(localStorage).
- 같은 기기, 같은 브라우저에서 열면 항상 이어서 사용할 수 있어요.
- **아래 "실시간 공유 설정"을 하면** 세린 패드·다윤 패드·부모님 폰이 **같은 데이터를 실시간으로 함께** 보고 체크할 수 있어요.

---

## 🔗 실시간 공유 설정하기 (여러 기기에서 함께 보기)

> 한 번만 설정하면, 한 기기에서 도장을 찍을 때 다른 기기에 **몇 초 안에 자동으로** 반영돼요.
> 무료이며, 별도 비밀번호(로그인) 없이 가족이 같은 화면을 공유합니다.

### 1단계 — Firebase 프로젝트 만들기 (무료)
1. https://console.firebase.google.com 접속 → 구글 계정으로 로그인
2. **프로젝트 만들기** → 이름 아무거나(예: `choi-family`) → 만들기
   - Google 애널리틱스는 꺼도 돼요.

### 2단계 — 데이터베이스(Firestore) 켜기
1. 왼쪽 메뉴 **빌드 → Firestore Database** → **데이터베이스 만들기**
2. 위치는 `asia-northeast3 (서울)` 추천
3. 시작 모드는 **테스트 모드**로 시작 → 만들기
4. 만든 뒤 상단 **규칙(Rules)** 탭에서 아래 내용으로 바꾸고 **게시**:
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /{document=**} {
         allow read, write: if true;
       }
     }
   }
   ```
   > 비밀번호 없이 공유하는 방식이라, 주소(URL)와 설정값을 가족끼리만 알고 계시면 돼요.

### 3단계 — 설정값을 앱에 넣기
1. Firebase 콘솔 좌측 위 **⚙️ → 프로젝트 설정**
2. 아래 **내 앱**에서 **웹(`</>`)** 아이콘 클릭 → 앱 등록(이름 아무거나)
3. 화면에 나오는 `firebaseConfig` 값(apiKey, projectId, appId 등)을 복사
4. 이 폴더의 **`firebase-config.js`** 파일을 열어 `PASTE_...` 부분을 복사한 값으로 바꾸기
5. 저장하면 끝! 앱 맨 아래에 **"☁️ 실시간 공유 켜짐"** 초록색 표시가 보이면 성공이에요.

> `firebase-config.js`의 `window.FAMILY_ID` 는 가족 데이터 칸 이름이에요. 그대로 둬도 되고 바꿔도 돼요.

## 🌐 인터넷에 올리기 (패드에서 같은 주소로 열기) — GitHub Pages

세린·다윤 패드에서 같은 주소(URL)로 접속하려면 웹에 올려야 해요.

1. GitHub 저장소 → **Settings → Pages**
2. **Build and deployment → Source** 를 **Deploy from a branch** 로
3. **Branch** 를 `main`(또는 사용 중인 브랜치), 폴더는 `/(root)` 로 선택 → **Save**
4. 1~2분 뒤 생기는 주소(예: `https://hongdonmax.github.io/family/`)를 패드 브라우저에서 열고 **홈 화면에 추가**하면 앱처럼 써요.

> ⚠️ 이 저장소는 **비공개(private)** 상태예요. GitHub Pages 무료 호스팅은 보통 **공개(public) 저장소**에서 동작해요.
> - 가장 간단: 저장소를 **public** 으로 바꾸기 (Settings 맨 아래 Danger Zone). 코드만 공개되고, 아이 기록 데이터는 Firebase에 있어 공개되지 않아요.
> - 비공개를 유지하고 싶다면 **Netlify**(netlify.com)에 무료로 올리는 방법도 있어요. 원하시면 도와드릴게요.

## 🗂 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 구조 (이 파일을 열면 됩니다) |

| `app.js` | 도장·스티커·달력·실시간 공유 로직 |
| `firebase-config.js` | 실시간 공유를 위한 Firebase 설정값 (여기를 채워요) |
